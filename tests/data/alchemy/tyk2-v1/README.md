# TYK2 and three congeneric ligands, version 1

The shared preparation for the protein–ligand campaign
([docs/development/protein-ligand-campaign.md](../../../../docs/development/protein-ligand-campaign.md)):
one protein, three ligands, prepared ONCE here and reused by every method. Four methods preparing
their own protein four times is four different proteins.

All neutral and congeneric: an acetamide, its propionamide and its isobutyramide. Each `LOCAL-`

`md-openmm build-top --parameterize`, openff-2.2.1, ~73 s each, created once and reused in every
environment.

## Force field: ff14SB + TIP3P, and why not ff19SB + OPC

An OPC-solvated leg applies OPC's rounded `coulomb14scale` (0.833333) to every 1-4 pair, the
ligand's included, while a vacuum leg applies the package's exact 5/6. `matched_legs` refuses that
pair, because the ligand's intramolecular Hamiltonian would be a different function in the two
legs of one cycle — so ABFE and RBFE, which need exactly that pairing, would be blocked. ff19SB +
OPC is a later variant, unblocked by the backlog item that lets a vacuum build apply the solvent
leg's stated scale.

## The preparation step

Upstream renamed the caps UNK → ACE/NME but left their ATOM names as Maestro wrote them, and
force-field templates match on names. `build-top` therefore refuses the protein:

```text
build-top: -i input/complex.pdb: 2 residue(s) are missing heavy atoms
           (A:889 ACE lacks C CH3; A:1178 NME lacks C N).
```

The atoms are all present. Following that message to `input.missing_atoms: add` would have had
PDBFixer add a SECOND copy of each. The fix is twelve renames, listed in `CAP_RENAMES` in
[`build_tyk2_fixture.py`](build_tyk2_fixture.py) and applied by it:

| residue | Maestro | template |
|---|---|---|
| ACE 889 | `C1` `O1` `C2` `H2_1` `H2_2` `H2_3` | `C` `O` `CH3` `HH31` `HH32` `HH33` |
| NME 1178 | `N1` `HN1` `C1` `H1_1` `H1_2` `H1_3` | `N` `H` `CH3` `HH31` `HH32` `HH33` |

No other atom is touched. `prepared/protein_caps_renamed.pdb` is the result, and
`prepared/complex_ejm_*.pdb` are that protein plus each ligand's heavy atoms as one HETATM residue
(chain B, resid 1) at the deposited pose; the hydrogens are the package's, placed by
`ligands.mapping`. `build_tyk2_fixture.py --check-prepared` re-derives all four and refuses if a
committed file differs.

## What is committed, and what is not

The built Systems are NOT here: three complexes are 56 MB of generated bytes. Committed instead
are the inputs, the prepared structures, the three packages, the nine build configurations, and
the nine build RECORDS (`records/<ligand>/<kind>/built.log`, with `environment.hostname`,
`environment.user` and the invoked `md_openmm.py` path replaced by `<redacted>`) — so the
provenance of the builds that were run is in git even though their output is not. Total ~2.8 MB.

```bash
python build_tyk2_fixture.py --out <dir>                          # all nine builds
python build_tyk2_fixture.py --out <dir> --ligand ejm_31 --kind complex
```

`$MD_DATA` is set to an empty directory inside `--out` for every build: the machine's catalog is
never read or written, and the packages here are the only ones used.

## What was built, and what it measured

ff14SB + TIP3P, PME 0.9 nm, HBonds, rigid water, cube.

| build | particles | box edge | wall time |
|---|---|---|---|
| complex (each ligand) | 53,030 / 53,030 / 53,027 | 8.238 nm | ~28 s |
| ligand solvated (each) | 1,733 / 1,928 / 1,913 | ≥ 2.655 nm | ~5 s |
| ligand vacuum (each) | 32 / 35 / 38 | — | ~2 s |

Every periodic box clears 2 × cutoff + 0.8 nm, the margin `ethane-tip3p-v2` exists to enforce.
The complexes carry 48 Na+ / 44 Cl− and ~16,000 waters; protonation is OpenMM's at pH 7 (81
recorded assignments, the histidines among them).

Topology plans over these builds (`md_tools.alchemy.topology`), automatic maps
(`rdkit-fmcs-heavy/1`, 21 heavy-atom MCS, symmetry-equivalent alternatives only):

| edge | mapped | A-only | B-only | hybrid plan (complex) | endpoint recovery |
|---|---|---|---|---|---|
| `ejm_31`→`ejm_42` | 31 | 1 | 4 | 16 s | complex 5.6e-09 / 3.7e-09 kJ/mol; solvated 7.1e-15 / 1.4e-14 |
| `ejm_31`→`ejm_43` | 30 | 2 | 8 | 16 s | solvated 4.3e-14 / 7.3e-11 kJ/mol |

Dual topology builds for both edges in both environments. Single topology is refused on these
pairs in an HBonds environment, correctly: mapping a hydrogen onto a heavy atom would make a
constraint appear along the path.
